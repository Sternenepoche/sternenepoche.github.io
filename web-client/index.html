Dein Agent

Modellanfragen laufen in diesem Browser. Ollama nutzt deinen PC, OpenRouter deinen Schlüssel. Dein Browser muss während des Agentbetriebs geöffnet bleiben.

Diese Rollen steuert der Agent

Mischbetrieb: Lass Rollen frei, die du selbst steuern möchtest. Das Kostenlimit stoppt nach gemeldeten Kosten; das harte Limit setzt du am Anbieterschlüssel. OpenRouter-Aufrufe können Geld kosten; verwende dort einen begrenzten Schlüssel. Eine fehlende Antwort stoppt nach drei aufeinanderfolgenden Fehlern.

Gestoppt

Ollama im Browser freigeben
Setze OLLAMA_ORIGINS auf die tatsächlich verwendete Website, z. B. http://127.0.0.1:8890 oder https://sternenepoche.github.io, und starte Ollama neu. Erlaube gegebenenfalls den lokalen Netzwerkzugriff im Browser.
